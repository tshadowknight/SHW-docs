**Mobile Save file migration for version 1.0.5**
This only applies to the Mobile version and only when updating from a previous version!
This requires a PC or root!
1) Install Super Holo Wars - Export Save.APK, it will update the old APK
2) Run the game once to the title screen, this will create the save files in the 'Internal storage\Android\data\com.example.rpgm\files\save' folder
3) Close the App.
4) Install the latest version v1.0.5+ APK, this will create a new app
5 Run the game once to the title screen, this will create the 'Internal storage\Android\data\com.tshadowknight.superholowars\files\save' folder
6) Close the App.
7) Now connect your device to a PC or use a root access filemanger to copy the save files from 'Internal storage\Android\data\com.example.rpgm\files\save' to 'Internal storage\Android\data\com.tshadowknight.superholowars\files\save'

After launching the new App and veriyfing the saves are present you may remove the old App.

**Using Custom BGM**
!The game must be closed when modifying custom BGM
!All files used must be in .ogg format
1)Create the bgm_custom folder if it does not exist yet, it is created automatically when launching the game. You can also manually create it. It goes in the same folder as the 'save' folder
2)Place custom .ogg files in the bgm_custom folder
3)Launch the game, custom BGM are now available in the Jukebox and BGM assign menu in the Options menu
*Note: The .ogg files support the LOOPSTART and LOOPLENGTH metadata tags used to loop songs in RPG Maker, so you can make your custom BGM loop correctly. A tutorial is available here: https://forums.rpgmakerweb.com/threads/make-looping-bgm-part-1-ogg-vorbis.10987/
